## Описание

Проект представляет собой многопоточную симуляцию экосистемы острова, где взаимодействуют:
- хищники
- травоядные
- растения

Каждый шаг симуляции (тик) обновляет состояние мира:
- перемещение животных
- питание (охота и поедание растений)
- размножение
- рост растений
- сбор статистики

---

Система построена вокруг фазового симуляционного цикла:

1. Move phase - фаза движений
2. Eat phase - фаза поедания
3. Reproduction phase - фаза размножения
4. Plant growth phase - фаза роста растений (добавления сущностей РАСТЕНИЕ)
5. Confirm changes (применение изменений)

---

## Модель острова

- Island — контейнер клеток
- Cell — базовая единица пространства
- Position — координаты на острове

Каждая клетка содержит:
- животных
- растения
- временные буферы (новорожденные, новые растения)

---
### Животные
Все сущности наследуются от `Entity`:

Поддерживаемые типы:
- хищники (Wolf, Fox, Bear, etc.)
- травоядные (Rabbit, Deer, Sheep, etc.)
- растения

### Поведение:
- перемещение (move)
- питание (eat)
- размножение (reproduce)
- смерть (die)

---

##  Симуляция

Каждый тик выполняет:

- обработку всех клеток через многопоточный executor
- обновление состояния животных
- применение изменений
- сбор статистики

#### Многопоточность:
- используется `ExecutorService`
- пул потоков: CPU cores * 2

Каждая клетка обрабатывается как отдельная задача.
### В данный момент присутствует гонка межфазных состояний, переписываю полностью проект на другую модель.

---

### Собираются метрики:
- рождаемость
- смертность
- смерть от голода
- неуспешная охота
- количество перемещений


## 🧾 Конфигурация

Конфигурация загружается из YAML-файлов, расположенных в classpath приложения:


#### src/main/resources/

#### ├── island_config.yaml
#### ├── entity_config.yaml
#### └── eat_config.yaml

На данный момент конфигурация читается только из ресурсов приложения (classpath).
Для использования внешних файлов потребуется доработка загрузчика.

---

## Сборка
Проект использует Maven для управления зависимостями и упрощения сборки - используются библиотеки Jackson.

Команда на сборку .jar: 

#### ` mvn clean package `


После сборки файл будет находиться в:

`target/island-simulation.jar`

Запуск приложения 

#### `java -jar target/island-simulation.jar`
